# 데이터 명세

- 구성: 1장 데이터 목록 → 2장 용도별 데이터 기간 → 3장 API 수집 상세 → 4장 크롤링 수집 상세 → 5장 라벨 정의 → 6장 기준값 분석 → 7장 확인 필요 항목
- 수집 방식 구분
  - API: 기관이 제공하는 공식 API를 인증키로 호출
  - 크롤링: 웹 페이지를 요청해 HTML·첨부에서 데이터를 추출. FinanceDataReader는 라이브러리가 웹 페이지(네이버 증권 시세 등)를 읽어 오는 방식이므로 크롤링으로 분류
- 상태 표기: 확인 완료(직접 호출·수집 확인), 확인 완료(팀원), 미확인, 미착수

#### 상장폐지 종목 조회
- FinanceDataReader `KRX-DELISTING`의 2015년 이후 주권 638건 중 593건이 고유번호 목록에 종목코드로 매칭. 매칭 안 된 45건은 모두 우선주(종목코드 끝자리 0 아님)로, 라벨 대상에서 제외되므로 영향 없음
- 고유번호 목록의 회사명은 최신 상호이므로 폐지 당시 이름과 다를 수 있음 (예: 에이아이비트 → 제이앤케이인더스트리). 매칭은 종목코드 기준
- 상장폐지 종목도 재무제표와 감사의견 조회 가능. 단, 감사의견 거절로 폐지된 마지막 사업연도는 재무제표가 없는 경우 있음

| 종목 | 사업연도 | 재무제표 (CFS / OFS) | 감사의견 (당기) |
|---|---|---|---|
| 제이앤케이인더스트리(039230) | 2018 | 237개 / 158개 | 적정 |
| 제이앤케이인더스트리(039230) | 2019 | 242개 / 147개 | 의견거절 |
| 럭슬(033600) | 2018 | 없음 / 105개 | 적정 |
| 럭슬(033600) | 2019 | 없음 / 없음 | 의견거절 |

#### 처리 규칙
- 연결재무제표가 없는 회사가 있으므로 `CFS` 조회 후 status 013이면 `OFS`로 대체
- 감사의견 값의 표기가 회사·연도마다 다름 ("적정", "적정의견", 결측). 한정·부적정·의견거절 키워드 기준 정규화 필요
- 감사의견 API의 `bsns_year` 값은 연도가 아니라 "제56기(당기)" 형식. 당기 행만 사용하고 연도는 요청한 `bsns_year`로 기록
- 사업보고서 제출 전(3월 말 이전)에는 직전 연도 재무제표가 없으므로 예측 기준일 4월 1일 시점에는 t-1 사업연도 사용 가능 여부를 제출일(`rcept_no` 앞 8자리)로 확인
- 호출 한도: OpenDART 안내 기준 개인 키 일 20,000회 (이번 확인에서 한도 도달 시험은 하지 않음). 상장 약 2,700개사 × 10개년 × 재무·감사의견 2종 약 54,000회이므로 최소 3일 분할 수집 필요

**KOSPI PBR 확보 방법**

| 방법 | 내용 | 판단 |
|---|---|---|
| ② 직접 계산 (채택) | 아래 계산 방식으로 시가총액 합계 ÷ 자본 합계를 주 단위로 계산 | 자동 갱신 가능, 이용약관 문제 없음. KRX 공식 값과 정의가 달라 근사값임 |
| ① KRX 화면 수작업 다운로드 | 로그인 후 화면에서 직접 내려받기 | 사용하지 않음 (팀 결정). 수작업이라 주간 자동 갱신 불가 |
| ①-b pykrx 등 자동 수집 | 계정으로 프로그램 로그인 후 자동 조회 | **사용하지 않음.** 이용약관 제10조 ② 위반 |

**직접 계산 방식**

| 항목 | 내용 |
|---|---|
| 정의 | KOSPI PBR(t) = Σ 시가총액(t) ÷ Σ 자본(t), 대상은 t 시점 유가증권시장 상장 보통주 |
| 계산 주기 | 매주 마지막 거래일 (F-30 판단일과 같음) |
| 기간 | 2015-01-02(2015년 첫 거래일)부터. 휴장일(주말·공휴일·연말 휴장 등)은 제외하고 거래일만 사용 |
| 시가총액 (2020-01-02부터) | 금융위원회 주식시세정보 `mrktTotAmt` (`mrktCtg` = KOSPI) |
| 시가총액 (2015 ~ 2019) | FinanceDataReader 종가 × DART 주식 총수(보고서 기준 발행주식수). 금융위 API 제공 기간 이전이라 대체 |
| 자본 | DART 재무제표의 지배기업 소유주지분 (연결 `CFS`), 연결이 없으면 별도 `OFS`의 자본총계 |
| 자본 시점 | 각 회사의 가장 최근 정기보고서(분기·반기·사업보고서) 중 **공시일(접수일)이 t 이전**인 것. 공시 전 값은 사용하지 않음 (미래 정보 방지) |
| 제외 대상 | 우선주, 자본이 0 이하인 회사(자본잠식, 분모 왜곡 방지), 자본 값이 없는 회사 |

- 주식수 변화로 설명되지 않는 ±30% 초과 변화는 제외: 1,626건 (정리매매, 상장 직후, 장기 거래정지 후 재개 등)

**보정 검증 (FinanceDataReader 수정주가와 변동성 비교)**

| 대상 | 종목 수 | 차이 절대값 중앙값 | 0.5%p 초과 |
|---|---|---|---|

| 보정 없는 무작위 종목 | 16 | 0.17%p | 0 |

- 0.5%p 초과 65종목 중 차이가 큰 상위 사례는 FinanceDataReader 쪽 오류. 예: 아이오케이(078860) 2023-12-27 20:1 주식 병합을 FinanceDataReader는 보정하지 않아 하루 +1,870%로 계산됨 (변동성 180%). 금융위 종가 × 상장주식수(시가총액)는 병합 전후 연속
- 보정 없는 종목의 0.1~0.4%p 차이는 두 출처의 120거래일 구간 차이(종목별 거래일 기준과 시장 거래일 기준)로 추정
