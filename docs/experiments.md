#### 1-6. 운영 규칙

- Vault에 올리는 후보는 시장·종목 각 2개 이하. 후보가 2개면 우선순위를 미리 정하고, 첫 번째가 통과한 경우에만 두 번째를 판정
- 개발 구간에서 시험한 모델·변수 조합 수를 3절에 기록. 20개 이상이면 ①의 하한 기준을 단측 97.5%로 강화
- Vault 보고서에 시장 상황을 함께 기록: 실제 상승 비율, 시장 변동성 배너가 켜진 주 수, 학습 범위 밖 변수 값이 나온 주 수
- Vault 결과를 보고 모델·변수·기준을 고쳐 같은 Vault로 다시 평가하지 않음
- 기준값은 연 1회 재학습 시 재판정

**결론**

- 금리차 효과: 6개 비교 모두 신뢰구간이 0을 포함해 차이가 있다고 말할 수 없음
