### 화면 설계 원칙

| 원칙 | 화면 반영 |
| --- | --- |
| 결론 우선 | 메인 맨 위에 한 줄 결론 → 살펴볼 종목 카드 → 2×2 위험 지도 순. 상세 지표는 접어 둠 |
| 5\~10분 점검 | 첫 방문은 입력 → 평가 2단계로 메인 도달. 로그인 재방문은 로그인 직후 재평가된 메인 표시 |
| 두 축 분리 | 재무 위험과 주가 변동 위험 배지를 항상 나란히 표시. 합산 점수 미표시 |
| 쉬운 말 | 전문 용어에 툴팁 풀이, 등급마다 안내 문구 |
| 근거 확인 | 기준 시점·데이터 범위·출처를 표시하고, 상세 근거는 펼치기나 상세 화면에서 선택적으로 확인 |
| 투자 권유 없음 | 모든 화면에 면책 문구. 매수·매도·비중 조절 표현 금지 |
| 상태 안내 | 로딩, 결과 없음, 오류마다 안내 문구와 다음 행동 제시 |
| 개인정보 | 체험 모드 상시 안내. DB 저장은 사용자의 명시적 동작으로만 수행 |

### ID 규칙

| 접두어 | 대상 | 예 |
| --- | --- | --- |
| `SCR-xx` | 페이지 | `SCR-02` 포트폴리오 종합평가 |
| `POP-xx` | 모달·팝업 | `POP-01` 로그인·가입 |
| `CMP-xx` | 여러 화면에 공통으로 붙는 구성요소 | `CMP-01` 플로팅 챗봇 |
| `<화면 ID>-Exx` | 화면 안의 요소 | `SCR-02-E01` 한 줄 결론 |

## 2. 화면 목록

페이지 4개, 모달 4개, 공통 구성요소 4개와 공통 레이아웃으로 구성됨. 로그인 없이 쓸 수 있는 범위는 SCR-01\~03과 챗봇이며, 저장·이력·삭제만 로그인이 필요함.

| ID | 화면명 | 유형 | 진입 경로 | 접근 조건 | 요구사항 |
| --- | --- | --- | --- | --- | --- |
| SCR-00 | 공통 레이아웃 | 공통 틀 | 모든 페이지 | 전체 | F-01, F-27 |
| SCR-01 | 보유 종목 입력 | 페이지 | 첫 화면 (체험 모드), SCR-02 \[종목 수정\] | 전체 | F-01, F-02, F-22 |
| SCR-02 | 포트폴리오 종합평가 (메인) | 페이지 | SCR-01 \[평가하기\], 로그인 후 자동 재평가 | 유효 종목 1개 이상 | F-08\~F-12, F-24, F-26, F-27, F-29 |
| SCR-03 | 종목 상세 | 페이지 | SCR-02 카드 \[자세히 보기\], 2×2 지도의 종목 점, 보유 종목 표 | 평가 결과 존재 | F-04\~F-07, F-28 |
| SCR-04 | 평가 이력 | 페이지 | 헤더 \[평가 이력\] | 로그인 | F-12 |
| POP-01 | 로그인·가입 | 모달 | 헤더 \[로그인 / 가입\], SCR-02 \[이 평가 저장하기\] (비로그인 시) | 비로그인 | F-03 |
| POP-02 | 체험 데이터 저장 확인 | 모달 | 로그인 성공 직후, 세션에 포트폴리오가 있을 때 | 로그인 | F-03 |
| POP-03 | 내 데이터 전체 삭제 확인 | 모달 | 헤더 계정 메뉴 \[내 데이터 삭제\] | 로그인 | F-03 |
| POP-04 | 리포트 다운로드 | 모달 | SCR-02 \[리포트 다운로드\] | 평가 결과 존재 | F-21 (선택) |
| CMP-01 | 플로팅 챗봇 | 공통 구성요소 | 모든 페이지 오른쪽 아래 버튼 | 전체 | F-13\~F-19, F-25 |
| CMP-02 | 용어 풀이 툴팁 | 공통 구성요소 | 점선 밑줄 용어에 마우스 올림·탭 | 전체 | F-27 |
| CMP-03 | 등급 배지 | 공통 구성요소 | SCR-02, SCR-03, SCR-04 | 전체 | F-04, F-28 |
| CMP-04 | 시장 변동성 배너 | 공통 구성요소 | SCR-02 맨 위. 시장 변동성 "주의"·"경고"일 때만 표시 | 전체 | F-29 |

### 핵심 동선 단계 수

| 과제 | 첫 방문 (체험 모드) | 재방문 (로그인) |
| --- | --- | --- |
| 이번 주 결론 확인 | 2단계: 종목 입력 → \[평가하기\] | 1단계: 로그인 |
| 살펴볼 종목의 이유 확인 | 2단계 (결론 아래 카드에 이유 2\~3줄) | 1단계 |
| 근거 상세 확인 | 3단계: 카드 \[자세히 보기\] | 2단계 |
| 지난주 대비 변화 확인 | 해당 없음 (이전 평가 없음) | 1단계 (메인 결론·카드에 변화 표시) |

## 3. 화면 흐름

체험 사용자는 로그인 없이 입력 → 메인 → 상세까지 진행하고, \[이 평가 저장하기\]를 누를 때만 로그인을 요구함. 재방문 사용자는 로그인 직후 저장된 포트폴리오로 메인이 재평가됨.

> 그림: 화면 흐름도 (진입 2개, 페이지 4개, 모달 2개, 분기 1개). 원본 문서의 그림은 저장소에 포함되지 않음

그림에서 생략한 이동: 종목 수정(SCR-02 → SCR-01), 리포트 다운로드(SCR-02 → POP-04), 데이터 삭제(계정 메뉴 또는 SCR-04 → POP-03 → 체험 모드 SCR-01), 저장된 포트폴리오가 없는 로그인(POP-01 → SCR-01).

## 4. 공통 레이아웃과 공통 구성요소

모든 페이지는 헤더(체험 모드 안내 포함), 본문, 면책 문구 푸터, 오른쪽 아래 플로팅 챗봇 버튼을 공유함. 체험 모드 안내와 면책 문구는 어떤 화면에서도 숨기지 않음.

### SCR-00 공통 레이아웃

| 요소 ID | 요소 | 유형 | 표시 데이터·동작 | 요구사항 |
| --- | --- | --- | --- | --- |
| SCR-00-E01 | 서비스명 | 링크 | 로고(`docs/assets/logo.webp`)와 "Stock Canary". 클릭 시 평가 결과가 있으면 SCR-02, 없으면 SCR-01 | - |
| SCR-00-E02 | 체험 모드 안내 | 안내 바 | 비로그인 시 "체험 모드: 창을 닫으면 데이터가 사라져요" + \[로그인하고 저장\] | F-01 |
| SCR-00-E03 | 로그인 / 가입 | 버튼 | 비로그인 시 표시. POP-01 열기 | F-03 |
| SCR-00-E04 | 계정 메뉴 | 드롭다운 | 로그인 시 닉네임 표시. 하위 항목 \[평가 이력\] \[내 데이터 삭제\] \[로그아웃\] | F-03, F-12 |
| SCR-00-E05 | 데이터 기준 시점 | 텍스트 | "데이터 기준: YYYY-MM-DD". 마지막 배치 적재일. 수집 실패로 갱신 주기보다 오래되면 "갱신 지연" 표시 (API data\_status: stale) | F-22 |
| SCR-00-E06 | 면책 문구 | 푸터 | "위험 신호와 근거 정보를 제공하며 매수·매도를 권하지 않아요. 최종 판단은 본인에게 있어요." | - |
| SCR-00-E07 | 플로팅 챗봇 버튼 | 고정 버튼 | 오른쪽 아래 고정. CMP-01 열기·닫기 | F-25 |
| SCR-00-E08 | 세션 만료 임박 안내 | 토스트 | 체험 모드에서 만료 전 "저장하지 않은 평가는 곧 사라져요" + \[저장하기\]. 표시 시점은 세션 만료 시간 확정 후 결정 | F-01 |

- 반응형 (제안): 데스크톱 기준 설계, 좁은 화면에서는 카드·표를 1열로 쌓고 챗봇 창은 전체 화면 시트로 표시

### CMP-02 용어 풀이 툴팁

| 항목 | 명세 |
| --- | --- |
| 대상 | 용어 사전(`glossary`)에 등록된 용어. 화면, 종합평가 리포트, 챗봇 답변 모두 적용 |
| 표시 | 용어에 점선 밑줄. 마우스 올림·키보드 포커스·탭 시 1\~2문장 풀이 |
| 예 | 유상증자, 자본잠식, 감사의견, 관리종목, 변동성, 최대낙폭, 베타, 업종 쏠림 |
| 데이터 | `GET /api/glossary`로 화면 진입 시 1회 로드 (기술 명세서 8-3) |

### CMP-03 등급 배지

| 축 | 표시 값 | 형식 |
| --- | --- | --- |
| 재무 위험 | 양호 / 관찰 / 주의 / 경고 / 경고(확정 사유) / 평가 제외 / 데이터 부족 | "재무 위험 · 주의" |
| 주가 변동 위험 | 매우 낮음 / 낮음 / 보통 / 높음 / 매우 높음 / 산출 불가(거래정지) | "주가 변동 위험 · 낮음" |

- 축 이름을 항상 함께 표시해 두 축을 혼동하지 않게 함
- 등급 변화가 있으면 배지 옆에 "지난주 관찰 → 주의" 형식으로 표시. 재무 위험 변화는 주가 변동 위험 변화보다 크게 강조 (F-24)
- 색상·아이콘 규칙은 12장 참고

### CMP-04 시장 변동성 배너

KOSPI 최근 20거래일 변동성이 과거 10년 분포 기준 "주의"·"경고" 상태일 때만 SCR-02 맨 위에 표시하는 안내 바이며, 종목 등급과 별개인 시장 전체 상황 안내임. 상태 판정 기준은 기술 명세서 6-3을 따름.

| 요소 ID | 요소 | 표시 데이터·동작 | 요구사항 |
| --- | --- | --- | --- |
| CMP-04-E01 | 배너 (주의) | 주의 색 바 + 아이콘 + "최근 시장 변동성이 평소보다 큼. 투자 판단에 유의" + 기준일 (예: "11/24 종가 기준") | F-29 |
| CMP-04-E02 | 배너 (경고) | 경고 색 바 + 아이콘 + "시장 변동성이 매우 큰 시기임. 투자 판단에 특히 유의" + 기준일 | F-29 |
| CMP-04-E03 | 최근 이력 문구 | 배너가 꺼져 있고 최근 7일 안에 주의·경고가 있었으면 결론(SCR-02-E01) 위에 작은 회색 문구. 예: "지난 7일 중 3일간 시장 변동성 주의 구간" | F-29 |
| CMP-04-E04 | 용어 풀이 | "시장 변동성"에 툴팁(CMP-02): "코스피가 최근 20거래일 동안 하루 평균 얼마나 오르내렸는지" | F-27 |
| CMP-04-E05 | 기준 설명 펼침 | 배너의 \[기준 보기\] 클릭 시 "과거 10년 중 변동성이 가장 큰 10% 구간에 해당해요" 같은 판정 기준 표시 (제안) | F-29 |

- 표시 위치: SCR-02 맨 위, 체험 모드 안내(SCR-00-E02) 바로 아래. 체험 모드 안내는 중립색 한 줄, 시장 배너는 주의·경고 색으로 구분. 다른 페이지 표시 여부는 미정
- 닫기 버튼 없음. 상태가 바뀌기 전까지 유지 (제안)
- 휴장일·수집 실패: 직전 거래일 상태와 기준일 유지. 상태 조회 자체가 실패하면 배너를 숨기고 오류는 표시하지 않음 (제안)
- 문구에 매수·매도·비중 조절 표현 금지

* 휴장일(정상)과 수집 실패(이상)를 구분해, 수집 실패로 기준일이 멈춘 경우에만 배너 옆에 "갱신 지연" 보조 표시 (제안)

## 5. SCR-01 보유 종목 입력

보유 종목과 수량을 받아 평가를 시작하는 첫 화면이며, 직접 입력과 CSV 업로드 두 방식을 제공함. 유효 종목이 1개 이상일 때만 \[평가하기\]가 활성화됨.

| 요소 ID | 요소 | 유형 | 표시 데이터·동작 | 요구사항 |
| --- | --- | --- | --- | --- |
| SCR-01-E01 | 안내 문구 | 텍스트 | "보유 종목과 수량을 입력하면 이번 주 살펴볼 종목을 알려드려요" | F-26 |
| SCR-01-E02 | 입력 방식 선택 | 탭 | \[직접 입력\] \[CSV 업로드\] | F-02 |
| SCR-01-E03 | 종목 검색 | 자동완성 입력 | 종목명 또는 6자리 코드 입력 시 후보 표시 (종목명, 코드, 시장). 후보에서 선택한 종목만 추가 가능 | F-02 |
| SCR-01-E04 | 수량 | 숫자 입력 | 1 이상 정수 | F-02 |
| SCR-01-E05 | 추가 | 버튼 | E03·E04가 유효할 때 활성. 목록(E06)에 추가 | F-02 |
| SCR-01-E06 | 입력 종목 목록 | 표 | 종목명, 코드, 시장, 수량(수정 가능), \[삭제\]. 금융업·신규 상장 종목은 "평가 제외 예정"·"데이터 부족 예정" 표시 (제안) | F-02, F-22 |
| SCR-01-E07 | CSV 업로드 | 파일 선택·끌어 놓기 | 형식 안내와 샘플 파일 다운로드 링크 함께 표시 | F-02 |

## 6. SCR-02 포트폴리오 종합평가 (메인)

위에서 아래로 시장 변동성 배너(주의·경고일 때만) → 결론 → 살펴볼 종목 → 2×2 위험 지도 → 접힌 상세 지표 → 종합평가 리포트 → 전체 종목 표 순으로 배치해, 첫 화면에서 "살펴볼 종목이 있는지"와 그 이유를 바로 확인하게 함.

> 그림: SCR-02 와이어프레임 (데스크톱 기준). 원본 문서의 그림은 저장소에 포함되지 않음. 이미지로 내보내 `docs/wireframes/`에 추가 필요

시장 변동성 배너(CMP-04)는 주의·경고일 때만 맨 위에 뜨며, 결론(E01), 살펴볼 종목 카드(E03), 위험 지도(E04)가 첫 화면에 들어오고 상세 지표(E06)는 기본으로 접혀 있음. 주의 색으로 강조한 칸은 "주가는 조용하지만 재무 위험 신호" 위치로, 카드의 "재무 위험 · 주의" 배지와 같은 색을 씀.

### 살펴볼 종목 카드의 사유 태그

| 기준 (F-26) | 태그 문구 | 직전 평가 필요 |
| --- | --- | --- |
| ① 재무 위험 "주의" 이상 | 재무 위험 주의 이상 | 아니오 |
| ② 재무 위험 등급 상승 | 재무 위험 상승 | 예 |
| ③ 주가 변동 위험 "매우 높음" 또는 2단계 이상 상승 | 주가 출렁임 매우 큼 / 주가 출렁임 급증 | 2단계 상승만 예 |

- 카드 정렬 (제안): 재무 위험 사유가 있는 종목 → 비중 큰 순
- 카드 사유는 해당 축 쪽으로만 안내 (예: 재무 "양호" + 주가 "매우 높음"이면 주가 변동 사유만, T-18)
- 체험 모드·첫 평가에서는 ②④와 ③의 상승 조건을 적용할 수 없으므로 결론 아래에 "지난 평가가 있으면 변화도 함께 알려드려요" 안내

* 시장 변동성 "주의"·"경고" 상태에서는 시장 전체 영향으로 ③(주가 출렁임 매우 큼) 사유 카드가 늘 수 있음 → 해당 카드에 "시장 전체 변동성이 큰 시기예요" 보조 문구를 붙이고, 결론 문장 끝에 "(시장 전체 변동성 주의 구간)"을 덧붙임 (제안)

## 7. SCR-03 종목 상세

한 종목의 두 축 등급과 그 근거(재무 위험 요인, 주가 변동 지표, 위험 공시, 차트)를 보여 주는 화면이며, 위에서 아래로 "등급 → 이유 → 근거 자료" 순으로 배치함.

| 요소 ID | 요소 | 유형 | 표시 데이터·동작 | 요구사항 |
| --- | --- | --- | --- | --- |
| SCR-03-E01 | 종목 헤더 | 텍스트 | 종목명, 코드, 시장, 업종, 내 포트폴리오 비중, 평가 기준일, \[메인으로\] | - |
| SCR-03-E02 | 두 축 등급 요약 | 배지 2개 + 문구 | 재무 위험 배지 + 등급 안내 문구, 주가 변동 위험 배지 + 등급 안내 문구, 2×2 칸 이름 | F-04, F-28 |
| SCR-03-E03 | 재무 위험 요인 | 문장 목록 | SHAP 상위 요인 문장 3개 내외 (예: "부채비율이 업종 평균의 2.3배", "3년 연속 영업손실") + 등급 경계까지의 거리 (예: "자본잠식률이 50%를 넘으면 한 단계 올라갈 수 있어요") | F-05 |

| SCR-03-E07 | 등급 추이 | 계단형 차트 2개 | 주별 재무 위험 등급, 주별 주가 변동 위험 등급 | F-07 |

| SCR-03-E09 | 변동성·낙폭 | 선 차트 | 고점 대비 낙폭 추이, 120거래일 변동성 추이 | F-07 |

- 주가 변동 위험 등급은 시장 대비가 아닌 종목 자체의 변동성 기준임. 시장 변동성 배너가 "주의"·"경고"이면 E02의 주가 변동 위험 배지 아래에 "시장 전체 변동성이 큰 시기라 여러 종목의 주가 변동 위험이 함께 높아져요" 문구 표시 (제안)
- 과거 120거래일 안에 거래정지 기간이 있던 종목은 거래량 0인 날을 빼고 변동성을 계산하며, 확보 기간이 120거래일보다 짧으면 E04 변동성 카드에 실제 기간 표시 (예: "최근 87거래일 기준") (제안)
- 최근 위험 공시(E05)의 원문 링크는 DART 공시이며, 한국거래소 시장조치는 원문 재게시 없이 조치 유형·지정일과 KIND 링크만 표시

* 재무 위험 요인(E03) 영역 제목은 인과로 읽히지 않도록 "모델 예측에 영향을 준 주요 요인"으로 표기
* 등급 경계까지의 거리 문구는 등급 기준값이 확정된 뒤에만 노출. 확정 전에는 요인 문장만 표시
* 등급 추이(E07)에서 등급이 바뀐 주에는 그 주의 위험 공시·시장조치를 점으로 표시하고, 점을 누르면 해당 공시 요약으로 이동 (가능한 범위)

## 8. SCR-04 평가 이력

로그인 사용자가 저장한 평가를 시점별로 다시 보고 두 시점을 비교하는 화면임. 과거 평가는 당시 결과를 읽기 전용으로 보여 주며 재계산하지 않음.

### 동작 규칙

- 창을 닫아도 대화 유지. 다른 페이지로 이동 후 다시 열면 `GET /api/chat/history`로 복원 (T-13)
- 열릴 때 입력창에 포커스, Esc로 닫기, 닫으면 플로팅 버튼으로 포커스 복귀
- 오류: LLM 실패 시 해당 질문에만 "답변을 만들지 못했어요" + \[다시 시도\], 한도 초과 시 입력창 비활성 + "오늘 질문 횟수를 모두 사용했어요"

* &#91;보도자료\] 유형에는 금융위원회, 금융감독원(보도자료·소비자경보), 한국거래소, 정책브리핑(재정경제부·공정거래위원회)이 포함되며 카드에 발행 기관명을 표시
* 원문 링크 규칙 (`docs/data_spec.md` 이용 조건): 금융감독원 원문은 금감원에 링크 사실을 통지한 뒤 연결, 한국거래소 자료는 본문을 카드에 펼쳐 보이지 않고 짧은 인용과 원문 링크만 표시

- 답변 생성 중에는 전송 버튼을 비활성화해 중복 요청 방지
- 일일 한도 초과 안내에 초기화 시점을 함께 표시 (초기화 기준 시각 미정)

## 11. 상태·예외 화면

실패한 영역만 안내하고 나머지 화면은 계속 쓸 수 있게 하는 것이 공통 원칙임. 기획안 테스트 케이스 T-01\~T-19와 시장 변동성 배너용 제안 케이스 T-20\~T-23, 화면 단위 제안 케이스 UI-01\~UI-05의 화면 반응을 아래 표에 모아 QA 기준으로 사용함.

| `UI-NO-WATCHLIST` | 살펴볼 종목 0건 | "이번 주 따로 살펴볼 종목은 없어요" + 평가 기준일·평가 제외 종목 안내. 위험이 없다고 단정하지 않음 |
| `UI-PARTIAL-DATA` | 부분 실패, 일부 종목 데이터 누락 | 성공한 영역은 그대로 표시, 실패 영역·누락 종목에만 사유와 \[다시 시도\] |
| `UI-STALE` | 데이터 갱신 지연 | 기준일 강조 + "갱신 지연" 표시. 결과는 직전 데이터로 계속 표시 |
| `UI-ERROR` | 전체 실패 | 오류 문구 + \[다시 시도\]. 사용자가 입력한 값은 유지 |
| `UI-SESSION-EXPIRED` | 체험 세션 만료 | "체험 시간이 끝나 데이터가 삭제됐어요" + \[새로 시작\] → SCR-01 |
| `UI-AUTH-EXPIRED` | 로그인 세션 만료 | POP-01을 열고 재로그인 후 원래 화면으로 복귀 |
| `UI-RATE-LIMIT` | 일일 요청 한도 초과 | 챗봇 입력창과 리포트 재생성 버튼 비활성 + 초기화 시점 안내 |
| `UI-MARKET-UNAVAILABLE` | 시장 변동성 상태 조회 실패 | 배너를 숨기고 오류는 표시하지 않음. 나머지 메인 화면은 정상 표시 (제안) |
| `UI-SAVE-ERROR` | 체험 데이터 저장 실패 | 세션 데이터 유지 + \[다시 시도\] |
| `UI-DELETE-ERROR` | 데이터 삭제 실패 | 완료로 표시하지 않음 + \[다시 시도\], 로그인 상태 유지 |

- 상태 코드는 API의 `data_status`·오류 코드와 1:1로 대응시키고, 대응표는 `shared/`에서 관리 (제안)

## 12. 표기 규칙과 미정 사항

등급은 색만으로 구분하지 않고 항상 축 이름과 등급 글자를 함께 표시함. 문구는 해요체, 짧은 문장을 쓰고 매매 판단으로 읽힐 표현은 쓰지 않음.

### 등급 색상 규칙 (제안)

| 축 | 등급 | 색 단계 |
| --- | --- | --- |
| 재무 위험 | 양호, 관찰 | 중립 |
| 재무 위험 | 주의 | 주의 색 |
| 재무 위험 | 경고, 경고(확정 사유) | 경고 색 (확정 사유는 아이콘 추가) |
| 재무 위험 | 평가 제외, 데이터 부족 | 회색 |
| 주가 변동 위험 | 매우 낮음, 낮음, 보통 | 중립 |
| 주가 변동 위험 | 높음 | 주의 색 |
| 주가 변동 위험 | 매우 높음 | 경고 색 |
| 주가 변동 위험 | 산출 불가(거래정지) | 회색 |
| 시장 변동성 배너 | 주의 | 주의 색 |
| 시장 변동성 배너 | 경고 | 경고 색 |

- 국내 증권 앱은 상승을 빨강, 하락을 파랑으로 표시하므로, 위험 등급에 빨강·파랑을 쓰면 주가 등락으로 오해할 수 있음 → 위험 등급은 주황 계열 단계색, 주가 차트 등락은 국내 관례 유지로 두 체계를 분리
- 색각 이상 사용자를 위해 아이콘과 등급 글자 병기

### 표현 규칙

| 사용하는 표현 | 쓰지 않는 표현 |
| --- | --- |
| 위험 신호, 살펴볼 필요가 있어요 | 부실 기업, 투자 부적격, 신용등급 |
| 재무 위험, 주가 변동 위험 (두 축 따로) | 종합 위험 점수, 두 축 합산 등급 |
| 사실과 근거 (공시명, 일자, 수치) | 매수, 매도, 비중을 늘리세요·줄이세요 |
| 지표별 기준 기간 (최근 120거래일, 과거 1년) | 앞으로 안전해요 등 미래를 보장하는 표현 |

- 수치에는 단위와 기준 기간을 함께 표기 (예: "과거 1년 최대낙폭")
- 처음 나오는 전문 용어는 툴팁(CMP-02) 적용

| 위치 | 문구 |

| SCR-00-E06 면책 문구 | "위험 신호와 근거 정보를 제공하며 매수·매도를 권하지 않아요. 최종 판단은 본인에게 있어요." |

* 배너 문구는 기획안 예시를 그대로 옮겨 개조식이며 다른 화면 문구는 해요체임. 해요체로 맞출 경우 예: "최근 시장 변동성이 평소보다 커요. 투자 판단에 유의해 주세요" (제안)
