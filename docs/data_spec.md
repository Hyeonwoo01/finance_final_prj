## 보도자료 수집 상세

### 금융위원회 홈페이지

| 항목 | 내용 |
|---|---|
| 목록 | `https://www.fsc.go.kr/no010101?srchBeginDt=YYYY-MM-DD&srchEndDt=YYYY-MM-DD&curPage=N` (페이지당 10건) |
| 상세 | `https://www.fsc.go.kr/no010101/<게시물 번호>` |
| 첨부 | `https://www.fsc.go.kr/comm/getFile?srvcId=BBSTY1&upperNo=<게시물 번호>&fileTy=ATTACH&fileNo=<n>` |
| 중복 방지 키 | `source` + 게시물 번호 |
| robots.txt | 전체 허용 |
| RSS | 보도자료 RSS(`fid=0111`) 안내는 있으나 확인 시점(2026-11-25)에 점검 중 응답 |

### 정책브리핑

| 항목 | 내용 |
|---|---|
| 목록 | `https://www.korea.kr/briefing/pressReleaseList.do?repCode=<부처 코드>&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&pageIndex=N` (페이지당 20건) |
| 부처 코드 | 재정경제부 `A00041`, 공정거래위원회 `C00001`. 쉼표로 묶어 함께 조회 가능 (`repCode=A00041,C00001`) |
| 상세 | `https://www.korea.kr/briefing/pressReleaseView.do?newsId=<newsId>` |
| 본문 | 상세 페이지에는 전재 안내와 첨부만 있고 본문 텍스트 없음. 첨부 PDF에서 텍스트 추출 |
| 첨부 | `https://www.korea.kr/common/download.do?fileId=<fileId>&tblKey=GMN` |
| 중복 방지 키 | `source` + newsId |
| robots.txt | 전체 허용 (Googlebot의 통합검색만 제외) |
| RSS | 확인되지 않음 |

### 금융감독원

| 항목 | 내용 |
|---|---|
| 보도자료 API | `https://www.fss.or.kr/fss/kr/openApi/api/bodoInfo.jsp?apiType=json&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD&authKey=<인증키>` |
| 요청 변수 | `apiType`(xml·json), `startDate`, `endDate`, `authKey`(32자리). 모두 필수 |
| 응답 항목 | `contentId`, `subject`, `publishOrg`, `originUrl`, `viewCnt`, `regDate`, `atchfileUrl`, `atchfileNm`(첨부는 `\|` 구분), `contentsKor`(본문 텍스트) |
| 인증키 | 금융감독원 홈페이지 OPEN API > 인증키 신청 (`/fss/api/apiKey/forInsert.do?menuNo=200273`), 개인·법인 구분. 이용약관 동의 필요. `.env`의 `FSS_API_KEY` |
| 중복 방지 키 | `source` + contentId |
| 소비자경보 목록 | `https://www.fss.or.kr/fss/bbs/B0000175/list.do?menuNo=200204&sdate=YYYY-MM-DD&edate=YYYY-MM-DD&pageIndex=N` |
| 소비자경보 상세 | `https://www.fss.or.kr/fss/bbs/B0000175/view.do?nttId=<nttId>&menuNo=200204`. 본문 HTML 제공 |
| 소비자경보 범위 | 미정 (투자 관련 경보만 또는 전체). 보이스피싱 등 일반 금융사기 경보 다수 포함 |
| robots.txt | 네이버 수집기(Yeti)만 일부 경로 제한. 보도자료·소비자경보 경로 제한 없음 |
| 저작권 | 비영리 개인 이용, 교육·연구 목적의 정당한 범위 인용 가능, 출처 표시 필수, 내용 무단 변경 금지. **다른 사이트에서 홈페이지 저작물을 직접 링크하는 경우 금융감독원에 링크 사실 통지 필요** (챗봇 출처 카드의 원문 링크 해당) |

### 공통

- 요청 간 간격을 두고 실패 시 재시도 (확인 중 간헐적 연결 끊김 발생)
- 텍스트만 사용하고, 챗봇 출처 카드에 기관명과 원문 링크 표시

## 라벨 정의

- 근거: 기획안 v3 2-3-2 (1)
- 재무 위험 모델의 양성 라벨은 예측 기준일 t(매년 4월 1일) 이후 12개월 내 부실 이벤트 발생 여부

| 구분 | 내용 | 출처 | 수집 위치 |

| ① 재무 사유 관리종목 지정 | 자본잠식, 매출액 미달, 감사의견 관련, 시가총액 미달 등 | KIND 투자유의사항 > 관리종목 | 팀원 PC (클라우드 IP 차단) |
| ② 재무 사유 상장폐지 | 감사의견 거절·한정, 자본잠식, 부도, 매출액·시가총액 미달, 장기 영업손실 등 | FinanceDataReader `KRX-DELISTING`의 `Reason` | 클라우드 가능 |
| ③ 감사의견 비적정 | 한정·부적정·의견거절 | DART 감사보고서, ②의 상장폐지 사유 | 클라우드 가능 |
| ④ 상장적격성 실질심사 사유 (논의 중) | 횡령·배임, 회계처리 위반 | KIND 투자유의사항 > 실질심사법인, 횡령 등 | 팀원 PC |
