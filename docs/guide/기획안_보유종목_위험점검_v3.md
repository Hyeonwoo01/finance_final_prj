## 1. 개요

### 1-1. 한 줄 소개
**내 보유 종목과 포트폴리오 전체의 위험을 "재무 위험"과 "주가 변동 위험" 두 축의 단계로 점검하고, 뉴스 기반 공포지수와 같은 업종 대장주 비교로 시장·업종 상황을 함께 보여 주며, 공시·보도자료·내 평가 이력을 근거로 질문에 답하는 포트폴리오 점검 챗봇 서비스**

### 1-2. 프로젝트 개요 (문제 → 목표 → 범위)
- 문제: 주식에 관심이 있어 몇 종목을 직접 사 두었지만, 주식 지식이 많지 않고 평일에는 확인할 시간이 없는 직장인 투자자가 많음. 공시, 재무제표, 금융당국 발표를 챙겨 보기 어렵고, 보더라도 "유상증자", "감사의견 한정", "자본잠식" 같은 용어의 뜻을 판단하기 어려움. 뉴스는 자극적인 제목 몇 개로 분위기를 짐작하고, 주가가 빠져도 업종 전체 흐름인지 내 종목만의 문제인지 구분하지 못함. 그래서 개별 종목의 위험 신호를 뒤늦게 알아차리고, 포트폴리오 전체가 특정 업종이나 고위험 종목에 얼마나 쏠려 있는지도 파악하지 못하는 경우가 많음
- 목표: DART 공시, 재무제표, 주가, 뉴스, 금융위원회·금융감독원·한국거래소 보도자료를 수집해 **종목별 재무 위험 등급과 주가 변동 위험 등급(근거 포함)**, **포트폴리오 종합평가**, 뉴스 긍정·부정 비율로 만든 **공포지수**, **같은 업종 대장주 비교**를 제공. 사용자는 공식 원문과 자신의 과거 평가 리포트를 함께 검색하는 **RAG 챗봇**에게 "왜 이 종목이 위험한지", "지난주보다 무엇이 달라졌는지"를 출처와 함께 질문
- 범위: 수집·정제 파이프라인, 재무 위험 예측 모델과 주가 변동 위험 지표, 뉴스 감성 분류와 공포지수, 업종 대장주 비교, 포트폴리오 지표 산출, LLM 공시 분류·종합평가 생성, 다중 출처 RAG 챗봇, 대시보드, Docker 기반 EC2 배포

### 1-3. 핵심 정의

| 항목 | 내용 |
|---|---|
| 사용자 | **주식을 잘 모르지만 관심이 있어 국내 주식 3~10종목을 직접 보유한 직장인 초보 투자자** (투자 경력 1~3년 정도, 재무제표·공시를 읽어 본 경험이 거의 없음) |
| 사용자의 현재 상황 | 평일에는 업무 때문에 주가 앱만 가끔 열어 보고, 종목에 무슨 일이 있는지는 뉴스나 커뮤니티 글로 뒤늦게 알게 됨. 공시나 보도자료를 직접 찾아 읽지 않음 |
| 판단 | "내 보유 종목 중 **이번 주에 신경 써서 살펴봐야 할 종목이 있는지, 있다면 왜 그런지, 지난주보다 무엇이 달라졌는지**" |
| 사용 맥락 | **주 1회**(주말이나 금요일 퇴근 후) 들어와 **5~10분 안에** 점검. 평소에는 들어오지 않음 |
| 사용자에게 필요한 것 | 결론 먼저(괜찮은지 / 살펴볼 종목이 있는지), 전문 용어 대신 쉬운 말, 용어가 나오면 바로 풀이, 근거가 궁금할 때만 상세 확인 |
| 포지셔닝 | 매수·매도·비중 조절을 추천하지 않고 **위험 신호와 근거 정보만 제공** (최종 판단은 사용자) |
| 확장 가능 사용자 | 증권사 PB의 고객 포트폴리오 점검 (고도화 방안으로만 기재) |

### 1-4. 기존 방식 대비 차별성

| 구분 | 기존 방식 | 본 서비스 |
|---|---|---|
| 공시 확인 | 종목마다 DART나 증권사 앱에서 직접 검색 | 보유 종목의 위험 공시를 자동 수집하고 위험 유형별로 분류 |
| 제도·당국 발표 확인 | 금융위·금감원·거래소 사이트를 따로 확인하거나 뉴스로 뒤늦게 인지 | 공식 보도자료를 수집해 보유 종목·업종과 관련된 내용을 챗봇에서 검색 |
| 공시 이해 | 전문 용어로 된 원문을 직접 해석하거나 아예 읽지 않음 | LLM 쉬운 말 요약 + 챗봇 Q&A(출처 표시) |
| 용어·지표 이해 | 모르는 용어를 따로 검색하거나 커뮤니티에 질문 | 화면의 용어에 바로 풀이 제공, 챗봇에서 "이게 무슨 뜻이야?"로 질문 |
| 점검 시간 | 주말에 종목마다 뉴스·커뮤니티를 뒤져 보는 데 시간이 오래 걸림 | 첫 화면에서 결론을 바로 보고, 5~10분 안에 주간 점검 완료 |
| 재무 건전성 판단 | 재무제표를 직접 보거나 커뮤니티 의견에 의존 | 재무 위험 등급(4단계)과 업종 평균 대비 비교 |
| 주가 위험 판단 | 등락률만 보고 감으로 판단 | 주가 변동 위험 등급(5단계)을 재무 위험과 **따로** 표시해 "회사가 위태로운지"와 "주가가 출렁이는지"를 구분 |
| 시장·종목 분위기 파악 | 뉴스 헤드라인과 커뮤니티 글을 훑어보고 감으로 판단 | 뉴스 긍정·부정 비율로 계산한 **공포지수**(시장)와 종목 뉴스 분위기를 과거 대비 위치로 표시 |
| 업종 비교 | 내 종목 주가만 보고 판단해 업종 전체 흐름인지 구분하지 못함 | 같은 업종 시가총액 상위 3개(**대장주**)와 주가 흐름·위험 등급·재무비율을 나란히 비교 |
| 포트폴리오 점검 | 증권사 앱의 수익률·평가금액 위주 | 위험 등급 분포, 업종 집중도, 변동성·상관관계, 위험 공시 노출 비중을 종합평가 |
| 이력 관리 | 지난번 점검 내용을 기억하거나 메모에 의존 | 종합평가 리포트를 저장해 챗봇이 "지난주 대비 변화"를 근거로 답변 |

### 1-5. 특장점

| 특장점 | 내용 |
|---|---|
| 다원 데이터 결합 | 재무제표(연·분기), 주가(일), 공시(수시), 금융당국 보도자료를 결합해 단일 지표 의존에서 탈피 |
| 두 축 위험 등급 | 재무 위험(보정된 확률 → 등급)과 주가 변동 위험(계산 지표 → 등급)을 분리해, 단일 점수보다 이유를 설명하기 쉽고 "주가는 조용하지만 재무가 나빠지는 종목"을 놓치지 않음 |
| 종목 → 포트폴리오 2단계 평가 | 종목별 두 축 등급과 근거(SHAP)를 포트폴리오 수준 지표(위험 노출 비중, 집중도, 변동성)로 묶고, 수치 검증을 거친 종합평가 리포트 생성 |
| 출처 유형을 구분하는 개인화 RAG 챗봇 | 공식 원문(공시·보도자료)과 AI 생성 개인 자료(평가 리포트)를 함께 검색하되, 답변에 **출처 유형을 구분해 표시**하고 사실 근거는 공식 원문을 우선 |

### 1-6. 선행 연구·기존 서비스 (차별점 주장 시 참고)

- **상용 서비스:** NICE BizLINE(거래처 신용 변동 알림), 한국평가데이터 KODATA AI 조기경보(해석 가능 ML + LLM 사유 설명), 증권사 앱의 공시 알림·포트폴리오 분석
  → "근거 설명이 있는 최초 서비스" 같은 주장은 하지 않음
- **국내 논문:** KOSDAQ 관리종목 지정 예측(LightGBM 정확도 약 82.7%, 2021), 관리종목 예측 앙상블 비교(2022), Merton 모형 기반 부도위험 ML 예측 등
  → 변수·라벨 설계 참고용. 논문의 정확도(%)는 표본 구성(균형 표본 여부)이 달라 우리 성능 목표와 직접 비교하지 않음
- **우리가 내세울 차별점:** 보유 종목·포트폴리오 단위 위험 점검, 공식 원문과 개인 평가 이력을 함께 쓰는 출처 구분형 RAG, 생성 문장의 수치 일치 자동 검증, 모델·라벨 정의·성능 공개

## 2. 핵심 기능

### 2-1. User Flow

```
첫 화면 = 체험 모드 (로그인 없이 바로 시작, 데이터는 세션에만 보관)
  - 상단 우측: [로그인 / 가입] 버튼, "체험 모드: 창을 닫으면 데이터가 사라집니다" 안내
   ↓
보유 종목 입력: 종목 검색 + 수량, 또는 CSV 업로드  (세션에 저장)
   ↓
포트폴리오 종합평가 (메인 화면, 결론 우선)
  - 시장 변동성 배너: 시장 변동성이 "주의"·"경고" 상태일 때만 맨 위에 표시
  - 공포지수: 시장 뉴스 분위기 점수(0~100)와 지난주 대비 변화, 대표 기사 제목
  - "이번 주 한 줄 결론": 예) "5종목 중 1종목(OO바이오)은 이번 주 살펴볼 필요가 있어요"
  - 살펴볼 종목 카드: 재무 위험 등급·주가 변동 위험 등급 배지 + 쉬운 말로 된 이유 2~3줄 + [자세히 보기]
  - 보유 종목 위험 지도(2×2): 재무 위험 × 주가 변동 위험 위치에 종목 표시
  - 그 아래(선택적으로 펼쳐 보기): 두 축 등급 분포, 업종 쏠림, 변동성, 위험 공시 노출 비중
  - LLM 종합평가 리포트 (쉬운 말, 용어에는 풀이 표시)
  - [이 평가 저장하기] 버튼 → 로그인 안 했으면 로그인·가입 창
   ↓
종목 상세: 두 축 등급과 추이, 재무 위험 요인 문장 설명("무엇이 바뀌면 등급이 바뀌는지" 포함), 주가 변동 지표, 최근 위험 공시 요약, 종목 뉴스 분위기, 업종 대장주 비교, 주가·재무 차트
   ↓
리포트 다운로드 (PDF·CSV)

[로그인 시]
  로그인·가입 (닉네임 + 비밀번호, 이메일·실명 미수집)
   ↓
  현재 세션의 포트폴리오·평가 리포트를 DB로 이관 (사용자 확인 후)
   ↓
  다음 방문 시: 로그인 → 저장된 포트폴리오 자동 불러오기 → 재평가
  → 지난주 평가 대비 변화 표시, 평가 이력 보기, 내 데이터 전체 삭제

[RAG 챗봇: 모든 화면 오른쪽 아래 플로팅 버튼 💬]
  버튼 클릭 → 우측 하단에 챗봇 창 열림 (닫아도 대화 내용은 세션 동안 유지)
  - "OO전자 이번 유상증자 목적이 뭐야?" → 공시 원문 근거
  - "최근 금감원 발표 중 내 종목과 관련된 거 있어?" → 보도자료 근거
  - "지난주 평가랑 비교해서 뭐가 나빠졌어?" → 내 평가 리포트 + 원문 근거 (로그인 사용자)
  - 체험 모드: 공시·보도자료 + 현재 세션의 평가 리포트만 검색
```

### 2-3. 종목 위험 평가 설계 (v3: 두 축 구조)

#### 2-3-1. 구조

종목의 위험을 성격이 다른 두 축으로 나누어 각각 등급을 매기고, **하나의 점수로 합치지 않습니다.** 합치면 가중치의 근거를 대기 어렵고, 초보 사용자에게 "왜 위험한지"를 설명하기도 어려워지기 때문입니다.

| 구분 | 재무 위험 (F-04) | 주가 변동 위험 (F-28) |
|---|---|---|
| 답하는 질문 | 이 회사가 1년 안에 관리종목·상장폐지 같은 사태를 맞을 가능성이 얼마나 되는가 | 이 주식의 가격이 얼마나 크게 흔들려 왔는가 |
| 사용자용 이름 | 재무 위험 | 주가 변동 위험 |
| 데이터 | 재무제표(분기), 공시(수시), Merton 부도거리 | 일별 주가·거래대금, KOSPI, 거래소 시장조치 |
| 산출 방식 | ML 모델 → 확률 보정 → 등급 기준표 + 규칙 덮어쓰기 | 계산 지표 → 등급 기준표 + 규칙 덮어쓰기 (ML 미사용) |
| 등급 | 4단계: 양호 / 관찰 / 주의 / 경고 | 5단계: 매우 낮음 / 낮음 / 보통 / 높음 / 매우 높음 |
| 갱신 | 모델은 연 1회 재학습, 점수는 주 1회 추론 | 주 1회 계산 |
| 등급 변화의 의미 | 드물게 바뀌며, 바뀌면 중요한 신호 | 자주 바뀌는 시장 상황 정보 |
| 검증 | 등급별 실제 부실 발생률, PR-AUC, 보정 | 등급과 이후 실제 변동성의 순위 상관 |

- 두 축은 어느 정도 상관이 있을 수밖에 없습니다(재무가 나쁜 기업은 주가도 많이 흔들림). 두 축의 상관계수를 측정해 기술문서에 기록합니다.
- "투자 부적격", "신용등급" 같은 표현은 쓰지 않습니다. 투자 판단이나 신용평가로 오해받을 수 있기 때문입니다.

#### 2-3-2. 재무 위험 모델 (F-04)

| 부실 이벤트 (양성) | ① **재무 사유** 관리종목 지정(자본잠식, 매출액 미달, 감사의견 관련, 시가총액 미달 등) ② 재무 사유 상장폐지 ③ 감사의견 비적정(한정·부적정·의견거절) ④ (논의) 상장적격성 실질심사 사유 발생(횡령·배임, 회계처리 위반) |

| 중도 이탈 | 12개월 안에 합병 등 비부실 사유로 상장폐지된 기업은 라벨 미확정으로 보고 학습에서 제외 |

| 상장 규정 근접도 | 자본잠식률·매출액·시가총액이 **t 시점에 적용되는 상장 규정 기준**에 얼마나 가까운지 (기준 대비 비율) |

| 공시 | 최근 1년 유상증자·CB·BW 발행 횟수, 최대주주 변경, 감사인 교체, 정정공시 횟수, 소송 공시, **계속기업 불확실성 강조사항**, **감사보고서 제출 지연**, **최대주주 주식담보 공시** |
| 주가 변동 변수 (이동) | 60·120일 변동성, 52주 고점 대비 하락률, 거래량 변화, 초과수익률은 **주가 변동 위험 축(2-3-3)으로 이동**. 제외 전·후 PR-AUC를 비교해 성능 손실을 기록하고, 손실이 크면 일부만 다시 포함 |

- 업종 평균은 **t 시점까지 공시된 기업만으로** 계산합니다 (누수 방지).
- 모든 변수는 공시일 기준으로 정렬하고, t 이전에 공개된 정보만 씁니다.

**(3) 모델 비교와 검증**

| 항목 | 내용 |

| 비교 모델 | ① **규칙 베이스라인**(상장 규정 근접도만 사용) ② Merton 부도거리 단독 ③ 로지스틱 회귀(해석용) ④ LightGBM |

**(4) 확률 보정과 등급 기준표**

- class weight로 학습한 모델의 확률은 부풀려져 있으므로, 검증셋으로 **확률 보정**(isotonic 또는 Platt)을 합니다. 2-4의 비중 가중 확률은 보정된 확률만 사용합니다.
- 등급은 **절대 확률 구간**으로 정합니다. 시장 내 순위(상위 N%)로 정하면 내 종목이 그대로여도 다른 종목 때문에 등급이 바뀌어, "지난주 대비 변화"가 의미를 잃기 때문입니다.

| 등급 | 기준 (예시, 라벨 집계 후 확정) | 사용자 안내 문구 (예시) |
|---|---|---|
| 양호 | 보정 확률 < 기저율의 0.5배 | 재무상 눈에 띄는 위험 신호가 적어요 |
| 관찰 | 기저율의 0.5배 ~ 2배 | 평균 수준이에요. 큰 변화가 있는지 가끔 확인해 보세요 |
| 주의 | 기저율의 2배 ~ 5배 | 재무 위험 신호가 평균보다 뚜렷해요. 이유를 확인해 보세요 |
| 경고 | 기저율의 5배 이상 | 재무 위험 신호가 강해요. 관련 공시를 꼭 확인해 보세요 |

- 등급별로 테스트 기간 이벤트가 충분하지 않으면 경계값을 조정하거나 3단계로 줄입니다.

|---|---|
| 현재 관리종목, 투자주의환기종목, 거래정지, 상장적격성 실질심사 진행 중 | 모델 점수와 관계없이 **"경고(확정 사유)"** + 사유 표시 |

**(6) 주간 운영**

- 모델은 사업보고서 시즌이 끝난 뒤(4~5월) **연 1회 재학습**하고, 매주 최신 재무·공시·Merton 부도거리로 **추론만** 합니다. 모델 버전을 점수와 함께 저장합니다.
- 등급 경계 근처에서 등급이 매주 오르내리지 않도록 **여유 구간**을 둡니다. 위험이 커지는 방향은 바로 반영하고, 위험이 줄어드는 방향은 경계값보다 일정 비율(예: 10%) 더 내려가야 반영합니다.

#### 2-3-3. 주가 변동 위험 지표 (F-28)

| 지표 | 계산 |
|---|---|
| 변동성 (기본 지표) | 종목의 최근 120거래일(약 6개월) 일별 수익률 표준편차. 화면에는 "하루 평균 몇 % 오르내림"으로 표시 |
| 하락 변동성 | 음(-) 수익률만으로 계산한 변동성 (최근 6개월) |
| 최대낙폭 | 최근 6개월 최대낙폭(MDD) |
| 베타 | KOSPI 대비 회귀 기울기 (최근 6개월) |
| 유동성 | 최근 20거래일 평균 거래대금 (적을수록 팔고 싶을 때 팔기 어려움) |
| 거래소 시장조치 | 투자주의·투자경고·투자위험, 단기과열 지정, 거래정지 |

**등급 산출 (기준값은 최근 5년 분포로 정한 초안)**

| 등급 | 변동성 기준 |
|---|---|
| 매우 낮음 | 일 변동성 1.9% 미만 |
| 낮음 | 1.9% ~ 2.6% |
| 보통 | 2.6% ~ 3.3% |
| 높음 | 3.3% ~ 5.0% |
| 매우 높음 | 5.0% 이상 |

- 기준값 정하는 방법: 최근 5년(점검 시점 기준 직전 5년) 여러 시점의 전 종목 120거래일 변동성 분포를 구하고, 분위수를 참고해 등급별로 종목이 고르게 나뉘도록 고정 숫자(일 변동성 %)로 확정. 초안은 2021-11 ~ 2026-11 월말 61개 시점, 코스피·코스닥 보통주의 20·40·60% 분위수(1.9 / 2.6 / 3.3). 마지막 경계는 80% 분위수(4.4%) 대신 5.0%로 조정해 "매우 높음"을 더 극단적인 종목에 한정하고 시장 변동성 배너 경고 기준과 맞춤 (팀 결정, `docs/data_spec.md` 주가 변동 위험 등급 기준값 초안)
- 적용 시 2021~2025년은 "매우 높음" 8~11%, "높음" 24~28%. 시장 변동성이 매우 큰 2026년은 "매우 높음" 28%
- 기준값은 연 1회 점검하고, 연중에는 고정
- 현재 기준값은 시장 변동성이 매우 컸던 최근 시기(분석상 2026년)가 분포에 들어가 평소보다 크게 잡혔을 수 있음. 이번 프로젝트에서는 현재 값을 사용하고, 운영 시에는 주기적으로 재계산해 고침
- 시장 대비로 나누지 않는 이유: 시장 전체가 출렁일 때 종목 등급이 함께 오르는 것은 실제로 위험이 커진 상황이므로 사용자에게 그대로 전달. 시장 전체 상황은 아래 시장 변동성 배너(F-29)로 별도 안내
- 보정 규칙: 유동성 하위 10% 종목은 한 단계 올립니다. 투자경고·투자위험 지정 종목은 "매우 높음"으로 덮어씁니다. 거래정지 종목은 "산출 불가(거래정지)"로 표시합니다.
- ML을 쓰지 않는 이유: 과거 변동성은 가까운 미래 변동성을 잘 설명하는 것으로 알려져 있고, 계산 근거를 사용자에게 그대로 보여 줄 수 있기 때문입니다.
- 화면에는 항상 "최근 6개월 기준이며 미래를 보장하지 않음"을 표시합니다.

**시장 변동성 배너 (F-29)**

| 항목 | 내용 |
|---|---|
| 지표 | KOSPI 최근 20거래일 일별 수익률 표준편차. 종목 등급(120거래일)보다 짧게 잡아 급변을 빠르게 반영 |
| 상태 기준 | "주의"는 과거 10년 같은 지표 분포의 상위 10% 이내(2.1%), "경고"는 5.0% 이상(종목 등급 "매우 높음" 기준과 같은 값, 팀 결정), 그 외 "표시 안 함" (일 변동성, 2016-11 ~ 2026-11 분포 기준) |
| 해제 기준 | 상위 20%(1.4%) 밖으로 내려갈 때 해제. 기준선 근처에서 배너가 매주 켜졌다 꺼지는 현상 방지 |
| 표시 | "주의"·"경고" 상태일 때만 화면 맨 위에 배너 표시. 배너가 꺼져 있어도 지난주(직전 결산 주)에 주의·경고가 있었으면 작은 문구로 안내 (예: "지난주 시장 변동성 주의 구간") |
| 갱신 | 매주 토요일 결산 방식. 그 주 마지막 거래일 종가 기준 20거래일 변동성으로 상태를 정하고 다음 결산까지 유지. 기준일 함께 표시 (예: "11/20 종가 기준") |
| 휴장일·수집 실패 | 그 주 마지막 거래일 기준으로 결산. 수집 실패 시 직전 결산 상태와 기준일 유지 |

| 상태 | 배너 문구 (예시) |
|---|---|
| 주의 | 최근 시장 변동성이 평소보다 큼. 투자 판단에 유의 |
| 경고 | 시장 변동성이 매우 큰 시기임. 투자 판단에 특히 유의 |

- 분포 기준값은 연 1회 갱신하고 연중에는 고정. 변동성이 큰 시기가 길어져도 기준이 함께 올라가지 않도록 하기 위함
- 확인 결과 (경고 5.0%, 주간 결산): 2020년 3월·2024년 8월·2025년 4월 급락 시기는 "주의"로 표시되고, "경고"는 2026년 7~8월(6주)뿐. 2020년 3월 코로나 급락(최대 4.50%)도 경고에 해당하지 않음 (`docs/data_spec.md` 시장 변동성 배너 기준값 초안)
- 시장 변동성이 매우 큰 2026년은 48주 중 43주에 배너가 표시됨. 상시 표시에 따른 주목 효과 저하 문제는 화면 작업 때 표시 방식과 함께 확정
- 배너는 시장 전체 상태 안내이며 매매 권유 문구를 쓰지 않음

#### 2-3-4. 화면 표시: 두 축 위치 (2×2)

두 축을 합친 점수 대신, 종목이 어느 위치에 있는지 보여 줍니다. 재무 위험은 "주의" 이상, 주가 변동 위험은 "높음" 이상을 "높음"으로 봅니다.

| | 주가 변동 위험 낮음 | 주가 변동 위험 높음 |
|---|---|---|
| **재무 위험 낮음** | 안정 | 재무는 괜찮지만 주가 출렁임이 커요 |
| **재무 위험 높음** | **주가는 조용하지만 재무 위험 신호가 있어요** (초보자가 가장 놓치기 쉬운 위치, 강조 표시) | 재무와 주가 모두 주의가 필요해요 |

- "살펴볼 종목" 선정 기준은 F-26에 정의합니다.

#### 2-3-5. 공포지수 (F-31, F-32)

| 항목 | 내용 |
|---|---|
| 목적 | 지금 시장과 보유 종목을 둘러싼 뉴스 분위기가 평소보다 얼마나 나쁜지 숫자로 안내 |
| 단위 | 시장: 증시 관련 검색어(코스피, 코스닥, 증시 등) 뉴스. 종목: 보유 종목명 뉴스 |
| 뉴스 범위 | 제목 + 요약문 + 링크. 본문은 수집하지 않음 (저작권) |
| 감성 분류 | 뉴스 1건을 긍정 / 중립 / 부정으로 분류. 후보는 LLM(GPT-4o-mini 등)과 금융 특화 한국어 분류 모델(KR-FinBert-SC 등). 수작업 라벨 표본으로 두 방식을 비교한 뒤 선택 |
| 주간 값 | 순부정 비율 = (부정 건수 − 긍정 건수) ÷ 전체 건수 (-1 ~ +1) |
| 시장 공포지수 | 그 주 순부정 비율의 과거 분포 내 백분위를 0~100 점수로 변환 (높을수록 공포). 구간 예시: 0~20 낙관 / 20~40 안정 / 40~60 보통 / 60~80 불안 / 80~100 공포 (기준값은 분포 확인 후 확정) |
| 종목 뉴스 분위기 | 최근 1주 긍정·중립·부정 건수와 직전 4주 평균 대비 순부정 비율 변화. 주 3건 미만이면 점수를 내지 않고 "뉴스 적음" 표시 |
| 애널리스트 보조 지표 (F-32, 선택) | 시장 단위: 최근 4주 리포트 중 목표주가 하향 비율의 과거 분포 내 백분위. 수집되면 뉴스 점수와 합쳐 공포지수를 만들고, 구성 요소별 점수도 함께 표시 (합산 방식은 7장 논의). 종목 단위: 투자의견 분포, 목표주가 상향·하향 건수. "목표주가까지 상승 여력 N%" 같은 표현은 매매 신호로 읽히므로 쓰지 않음 |
| 갱신 | 매주 토요일 결산 (시장 변동성 배너와 같은 주기), 기준일 표시. 수집 실패 시 직전 결산 값과 기준일 유지 |
| 표시 | 메인 상단 시장 상태 영역에 게이지와 지난주 대비 변화. 대표 부정·긍정 기사 제목 3개와 원문 링크 |

- 시장 변동성 배너(F-29)와의 관계: 배너는 실제 주가 출렁임, 공포지수는 뉴스 분위기. 주가는 조용한데 부정 뉴스가 늘어나는 경우처럼 두 값이 다르게 나올 수 있어 둘 다 표시. 두 값의 상관을 측정해 기술문서에 기록
- 공포지수는 현재 분위기 요약이며 이후 주가 방향을 예측하지 않음. "공포 구간은 매수 기회" 같은 해석 문구는 쓰지 않음
- 종목명이 일반 단어와 겹치는 종목은 제목에 종목명이 들어간 기사만 쓰고, 표본 검수로 잘못 연결된 기사 비율을 기록
- 과거 분포: 네이버 뉴스 검색 API는 검색어당 최근 1,000건까지만 조회되어 과거 분포 산출에 부족. 과거 분포는 빅카인즈에서 받고, 주간 갱신은 네이버 API로 수집. 두 출처의 기사 범위 차이로 점수가 달라지는지 겹치는 기간에서 확인

#### 2-3-6. 업종 대장주 비교 (F-33)

| 항목 | 내용 |
|---|---|
| 목적 | 내 종목의 움직임이 업종 전체 흐름인지, 내 종목만의 움직임인지 구분하도록 도움 |
| 대장주 선정 | 보유 종목과 같은 업종에서 시가총액 상위 3개. 보유 종목이 상위 3개 안에 있으면 자신을 빼고 다음 순위로 채움. 코스피·코스닥 합산. 매주 토요일 결산 기준 갱신 |
| 업종 분류 | F-09 업종 집중도와 같은 기업기본정보 업종 분류. 분류 수준(대·중·소분류)은 업종별 종목 수 분포 확인 후 확정 |
| 비교 항목 | 주가: 최근 1개월·6개월 수익률, 같은 기간 차트 겹쳐 보기 / 위험: 두 축 등급 / 재무: 부채비율, 영업이익률, 매출 성장률 / 뉴스 분위기(F-31) |
| 한 줄 안내 | 템플릿 문장. 예: "최근 1개월 OO는 -12%, 같은 업종 대장주 평균은 -10%로 업종 전체 흐름과 비슷해요" / "대장주 평균은 +2%인데 OO는 -15%예요. 종목 자체에 이유가 있는지 공시와 뉴스를 확인해 보세요". "비슷함"과 "다름"을 나누는 차이 기준은 수익률 차이 분포 확인 후 확정 |
| 예외 | 업종 종목이 4개 미만이면 있는 만큼만 표시하고 안내. 대장주가 금융업 등 "평가 제외"이면 등급은 "평가 제외"로 표시하고 주가·뉴스만 비교 |

- 새로 수집할 데이터가 거의 없음. 시가총액, 업종, 재무비율, 두 축 등급, 뉴스 분위기를 다시 사용
- 대장주와 비교하는 정보만 제공하고 "대장주로 바꾸세요" 같은 종목 교체 권유 표현은 쓰지 않음

### 2-4. 포트폴리오 종합평가 설계 (신규)

| 구분 | 지표 | 계산 방식 |
|---|---|---|
| 재무 위험 노출 | 비중 가중 재무 위험 확률 | Σ(종목 비중 × **보정된** 부실 확률). "평가 제외·데이터 부족" 종목은 빼고 계산하고 해당 비중을 따로 표시 |
| | 재무 위험 높은 비중 | 재무 위험 "주의"·"경고" 종목의 비중 합 (그중 "경고(확정 사유)" 비중 별도 표시) |
| | 위험 공시 노출 | 최근 90일 위험 공시 발생 종목의 비중 합 |
| 주가 변동 위험 노출 | 변동 위험 높은 비중 | 주가 변동 위험 "높음"·"매우 높음" 종목의 비중 합 |
| | 시장조치 노출 | 투자주의·경고·위험, 거래정지 종목의 비중 합 |
| 두 축 위치 | 2×2 위치별 비중 | 2-3-4의 네 위치별 비중 합. "주가는 조용하지만 재무 위험 신호" 위치의 비중은 강조 |
| 분산 | 업종 집중도 | 업종별 비중의 HHI, 최대 업종 비중 |
| | 종목 집중도 | 상위 3종목 비중, 종목 수 |
| 시장 위험 | 변동성·MDD | 최근 6개월 일별 수익률로 계산한 포트폴리오 변동성과 최대낙폭 |
| | 베타 | KOSPI 대비 회귀 기울기 |
| | 상관 | 종목 간 수익률 상관 행렬 (상관이 높은 종목 쌍 표시) |
| 변화 | 직전 평가 대비 | 위 지표들의 증감, 두 축 각각 등급이 바뀐 종목 |

- 포트폴리오 수준에서도 두 축을 하나의 "종합 위험 등급"으로 합치지 않고, 재무 위험 노출과 주가 변동 위험(변동성·MDD·베타)을 나란히 보여 줍니다.

**종합평가 리포트 생성 흐름**
1. 지표 계산(Python) → 구조화된 JSON (종목별 두 축 등급, 재무 위험 요인, 주가 변동 지표 포함)
2. LLM에는 **JSON 수치와 종목 위험 요인만** 전달 (보유 수량·금액·사용자 식별 정보 미전송)
3. 생성 문장 속 수치를 원본 JSON과 자동 대조하고, 불일치하면 재생성하거나 템플릿 문장으로 대체
4. 금칙어 필터("매수", "매도", "비중을 늘리세요" 등)
5. 체험 모드: 리포트를 **세션 메모리**에만 보관하고 챗봇은 세션 안에서만 검색
   로그인 사용자: 리포트를 DB에 저장하고 **개인 벡터 공간에 임베딩** (다음 방문 때도 챗봇 검색 대상)

### 2-5. RAG 챗봇 설계 (신규·확장)

| 항목 | 내용 |
|---|---|
| 화면 형태 | 모든 화면 오른쪽 아래 **플로팅 버튼** → 클릭 시 우측 하단 챗봇 창. 답변 아래에 출처 카드(유형 배지, 문서명, 일자, 원문 링크) |
| 문서 컬렉션 | `public_docs`: 공시 원문 청크, 공식 보도자료 청크 / `user_docs`: 로그인 사용자별 종합평가 리포트 (메타데이터 `user_id` 필수) / 체험 모드: 세션 메모리의 임시 리포트 (DB·VectorDB 미저장) |
| 메타데이터 | `source_type`(disclosure / press_release / user_report), `corp_code`, `published_at`, `title`, `url`, `user_id`, `generated_by`(AI 생성 여부) |
| 검색 | 질문에서 종목·기간을 추출해 메타데이터로 필터링 → public과 user 컬렉션을 각각 검색 → 합쳐서 재정렬 |
| 원문 우선 원칙 | 프롬프트와 후처리로 사실 주장에는 public 출처 인용을 강제. user_report는 "지난 평가 내용"을 말할 때만 근거로 사용 |
| 순환 오염 방지 | AI 생성 리포트는 원문 근거를 인용한 형태로만 저장. 챗봇 답변은 다시 RAG 자료로 저장하지 않음 |
| 격리 | `user_docs` 검색 시 로그인 사용자의 `user_id` 필터를 서버에서 강제 (클라이언트 입력 불신) |
| 거절 | 유사도 기준 미만이거나 근거가 없으면 거절. 매매 권유 질문도 거절 |
| 비용 제어 | 공시·보도자료 임베딩은 파이프라인에서 사전 처리. 실시간 LLM 호출은 챗봇 답변과 종합평가 생성만. 사용자별 요청 수 제한 |

**출처 유형별 활용 예**

| 질문 | 주로 쓰는 출처 |
|---|---|
| "OO바이오 전환사채 발행 조건이 뭐야?" | [공시] |
| "최근 금감원이 경고한 내용 중 내 종목 관련 있어?" | [보도자료] + [공시] |
| "코스닥 상장유지 기준 바뀐 거 내 종목에 영향 있어?" | [보도자료](거래소·금융위) + 종목 데이터 |
| "지난주 평가랑 비교해서 뭐가 나빠졌어?" | [내 평가 리포트] + 변화 원인 [공시] |

### 2-6. 성능 목표 (초안)

| 항목 | 목표 | 측정 방법 |
|---|---|---|
| 재무 위험 판별력 | LightGBM의 PR-AUC가 규칙 베이스라인·Merton 단독·로지스틱보다 높고, **기저율의 5배 이상**. 위험 상위 10% 기업이 테스트 기간 부실 이벤트의 **50% 이상** 포함 (수치는 라벨 집계 후 확정) | 시간 순 교차검증 + 2023~2025 테스트셋, 모델별 성능 비교표. 선행 논문의 정확도는 불균형 데이터에서 비교 불가하므로 인용하지 않음 |

### 3-3. 규모 감각
- 코스피·코스닥 약 2,600개사 + 상장폐지 기업, 약 10년 → 기업-연도 약 2만 5천 행
- RAG 공시는 최근 2~3년의 **위험 유형 공시만** 임베딩, 보도자료는 최근 5년분 (EC2 사양 부담 축소)
- 사용자 리포트는 사용자당 평가 횟수만큼만 쌓이므로 규모 부담은 작음
- 종목 뉴스는 전 종목(약 2,600개)을 하루 1회 검색. 네이버 검색 API 일 호출 한도 안에서 처리 가능한지 확인 필요

| 한계 | 대응 |

## 7. 팀 논의 필요 사항

1. **주제 확정:** 이 안으로 갈지, 검토했던 다른 후보로 갈지
2. **사용자 (v2 반영):** "주식을 잘 모르지만 관심 있고, 주 1회 들어와 점검하는 직장인 초보 투자자"로 정리함. 보유 종목 수 범위(3~10종목)와 테스터 모집 방법만 확정 필요
3. **계정 방식 (v2 반영):** 기본 체험 모드(세션) + 로그인 시 DB 저장으로 정리함. 세션 만료 시간과 로그인 이관 방식(자동 vs 사용자 확인)만 확정 필요
4. **재무 위험 라벨 정의 (v3 반영):** 재무 사유 관리종목 / 재무 사유 상장폐지 / 감사의견 비적정으로 정리함. **상장적격성 실질심사 사유를 라벨에 넣을지**, 라벨 창을 12개월과 15개월 중 무엇으로 할지 확정 필요
   - **두 축 구조 (v3 반영):** 재무 위험(4단계)과 주가 변동 위험(5단계)을 합치지 않고 따로 표시. 등급 수와 등급 이름, 등급 기준값 확정 시점(라벨 집계·변동성 분포 확인 후) 확정 필요
   - 주가 변동 변수를 재무 위험 모델에서 뺐을 때 성능 손실이 크면 일부를 다시 넣을지 판단 기준 필요
5. **보도자료 범위:** 금융위·금감원·거래소 중 어디까지 수집할지 확정 필요. 기간은 최근 5년으로 정리함 (3-1 용도별 데이터 기간)
6. **서비스 구성 방식:** Streamlit 단일 앱 vs FastAPI + 프론트 분리. 계정·세션 관리와 **오른쪽 아래 플로팅 챗봇**이 추가되어 분리 방식 쪽이 구현이 수월함 (Streamlit 유지 시 커스텀 컴포넌트 필요)
7. **역할 분담:** 역할 A·B·C와 협업 요청 방식으로 정리함 (7-1). 팀원(한도윤, 한규호, 안현우)별 역할 배정 확정 필요
8. **범위 조정:** v2에서 기능이 늘었으므로 필수와 선택을 다시 확인 (특히 F-19~F-24)
   - 참고: 플로팅 챗봇 UI는 F-25, 주가 변동 위험 등급은 F-28, 시장 변동성 배너는 F-29, 공포지수는 F-31, 애널리스트 의견은 F-32, 업종 대장주 비교는 F-33으로 추가 순서대로 번호를 붙임 (요구사항 ID 확정 시 재정렬)
9. **공포지수·업종 대장주 (F-31~F-33):** 공포지수는 시장·보유 종목 단위, 애널리스트 의견은 선택, 대장주는 업종 시가총액 상위 3개로 정리함. 아래 항목 확정 필요 (2-3-5, 2-3-6)
   - 뉴스 감성 분류 방식 (LLM / 금융 특화 분류 모델) 선택 기준
   - 애널리스트 지표를 공포지수에 합칠지, 합친다면 가중 방식
   - 업종 분류 수준 (대·중·소분류)
   - 종목 뉴스 분위기 급격한 악화, 대장주 대비 큰 수익률 차이를 살펴볼 종목(F-26) 기준에 넣을지
