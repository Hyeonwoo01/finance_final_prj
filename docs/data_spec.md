- 종가는 수정주가가 아님. 카카오(035720) 2021-04 액면분할에서 558,000원 → 120,500원으로 끊김. 수익률·변동성 계산 전 상장주식수(`lstgStCnt`) 변화로 분할·병합을 찾아 보정하거나, 수정주가를 주는 다른 출처와 비교 필요
- 거래정지 기간에도 행이 있고 종가가 직전 값으로 유지됨 (카카오 2021-04-12~14). 변동성 계산 시 거래량(`trqu`) 0인 날 제외 여부 결정 필요
- 2019년 이전 시세(10년 분포 확인, 2015~2019 라벨 학습 기간)는 이 API로 받을 수 없으므로 다른 출처 필요
- 일 단위 갱신은 전 거래일 종가 기준으로 다음 날 수집

### 공통 사항
- 확인 환경: 팀원 PC(국내 IP), 브라우저와 curl로 확인. 클라우드 환경의 접속 차단(이슈 #4 본문)과 달리 두 사이트 모두 정상 접속
- KIND 목록 조회는 모두 같은 구조: 메인 페이지(`method=...Main`)를 연 뒤 `searchForm`을 같은 `.do` 주소로 POST해서 목록 HTML 조각을 받음
  - 공통 파라미터: `method`(조회 메서드), `forward`(응답 화면), `currentPageSize`(15/30/50/100), `pageIndex`, `orderMode`, `orderStat`, `marketType`
  - 엑셀 다운로드: 같은 주소에 `forward`를 `..._down`으로, `currentPageSize=3000`으로 바꿔 POST
  - 응답 인코딩: 메뉴마다 UTF-8과 EUC-KR이 섞여 있음 (실질심사법인 등은 EUC-KR). 응답 헤더의 charset 기준으로 디코딩 필요
- 이용 조건 (H, 모든 KIND 메뉴와 한국거래소 보도자료 공통)
  - `kind.krx.co.kr/robots.txt`: 없음 (404 페이지로 이동)
  - `www.krx.co.kr/robots.txt`: 없음 (404)
  - 한국거래소 법적고지(`info.krx.co.kr/contents/KRX/06/06070200/KRX06070200.jsp`): 서비스의 저작권은 한국거래소에 있고, 사전 동의 없이 복제·전송·출판·배포하거나 제3자에게 배포하는 것을 금지
  - 판단: 내부 분석용 수집과 라벨 생성은 가능한 범위로 보이나, 수집 원문을 서비스 화면에 그대로 재게시하는 것은 사전 동의 대상. 서비스에는 가공 결과(등급, 사유 분류)와 원문 링크만 표시하는 방식 권장

### 처리 규칙
- 연결재무제표가 없는 회사가 있으므로 `CFS` 조회 후 status 013이면 `OFS`로 대체
- 감사의견 값의 표기가 회사·연도마다 다름 ("적정", "적정의견", 결측). 한정·부적정·의견거절 키워드 기준 정규화 필요
- 감사의견 API의 `bsns_year` 값은 연도가 아니라 "제56기(당기)" 형식. 당기 행만 사용하고 연도는 요청한 `bsns_year`로 기록
- 사업보고서 제출 전(3월 말 이전)에는 직전 연도 재무제표가 없으므로 예측 기준일 4월 1일 시점에는 t-1 사업연도 사용 가능 여부를 제출일(`rcept_no` 앞 8자리)로 확인
- 호출 한도: OpenDART 안내 기준 개인 키 일 20,000회 (이번 확인에서 한도 도달 시험은 하지 않음). 상장 약 2,700개사 × 10개년 × 재무·감사의견 2종 약 54,000회이므로 최소 3일 분할 수집 필요
- 회사 미지정 공시 목록은 3개월 단위로 나눠 호출. 2015-04~06 구간도 조회됨(6,721건)
